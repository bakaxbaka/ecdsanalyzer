About This Tool

This tool analyzes Bitcoin transactions for ECDSA signature vulnerabilities, including:

  • Nonce Reuse: Detects when the same nonce (k) is used in multiple signatures
  • Weak Signatures: Identifies signatures with low r or s values
  • Private Key Recovery: Attempts to recover private keys from vulnerable signatures
  • Address Monitoring: Tracks signature patterns across multiple transactions
